# AEGIS — компактные следы от пуль v13

Полная сборка на базе AEGIS mocap actions v12. Предыдущие анимации, карты, модели и механики сохранены. Изменён только модуль декалей попаданий (исходник и готовый runtime) и версия пакета; добавлены отчёты и тест метрик.

## Изменения
- Дерево: компактное отверстие, угловатые свежие сколы, разрывы вдоль волокон и отдельные щепки. Нет сплошного тёмного конуса вокруг отверстия.
- Металл: небольшая пробоина, разорванные светлые металлические кромки и отдельные царапины, без круглого слоя копоти.
- Грунт: неглубокое неровное повреждение, зернистый край и мелкие комочки; большое чёрное пятно убрано.
- Ткань: маленький несимметричный прокол и оборванные нити без тёмного круглого ореола.
- Бумага: маленький звёздчатый надрыв со светлыми загнутыми краями.
- Уменьшены физическая глубина параллакса и усиление нормалей — след не выглядит большой глубокой воронкой.
- Для косых попаданий растяжение новых материалов ограничено 2.1×. Для бетона сохранено прежнее поведение.
- Дополнительное затемнение полости новых материалов ослаблено: оно больше не затемняет всю область повреждения.
- Сохранены адаптация к цвету поверхности, направление древесных волокон, варианты следов, привязка к геометрии и удаление следов вместе с разрушенным участком.
- Бетон/кирпич/штукатурка оставлены эталоном: исходные шесть вариантов карт цвета, нормалей/высоты и параметров совпадают с исходными по SHA-256.

## Масштаб
Ниже ширина области проекции при фиксированном случайном значении 0.5. Это НЕ диаметр чёрного отверстия: большая часть прямоугольника прозрачна, само повреждение значительно меньше. Размер не привязан к калибру — в этой правке меняется визуальный профиль материала, не баллистика.

| Материал | Раньше | Теперь | Уменьшение ширины |
|---|---:|---:|---:|
| Металл | 11.75 см | 6.80 см | 42% |
| Дерево | 16.75 см | 9.10 см | 46% |
| Бумага | 7.00 см | 4.60 см | 34% |
| Ткань | 10.25 см | 5.50 см | 46% |
| Грунт | 21.50 см | 10.75 см | 50% |

## Проверки
- `npm run test:impacts:v13`: размеры, площадь тёмных пикселей, неизменность бетона.
- `npm run typecheck`: TypeScript всей сборки.
- Проекция и исчезновение следов при настоящем разрушении проверены на трёх картах: angar_map, forest_map_camp, stroyka_zarechye_v2.
- Проверены 12 цветовых сочетаний и крупные планы всех шести материалов, компиляция WebGL без ошибок и работа параллакса при наклонном взгляде.
- Проверены перемещение владельца следа, удаление геометрии, инстансы, повторное использование пула, ограничение числа следов и освобождение ресурсов.
- Отчёты: `docs/qa-impacts-v13/`, метрики: `docs/COMPACT_IMPACTS_V13_QA.json`.

Рельеф — normal mapping + parallax occlusion, не настоящая сквозная геометрическая пробоина. Полный общий `npm test` в этой правке не заявляется как пройденный; см. отчёты базовой v12 о существующем AI/occlusion тесте.

## Запуск / обновление
Полный архив распаковать и запустить обычным способом через локальный HTTP-сервер. Например, в папке aegis: `python3 -m http.server 8000`, затем открыть http://localhost:8000/ .

Отдельный PATCH не является полной игрой. Для него скопировать два файла из vendor/bullet-impacts поверх существующей v12: Decals.ts и bullet-impacts.js. Затем перезагрузить страницу без кэша. Файлы анимаций не заменяются.
