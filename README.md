# AEGIS 18.4 — Recast/BT/Rapier

Полная сборка игры. В этом выпуске гильзы и сброшенные магазины переведены на Rapier. Исправление запуска 18.3.1 сохранено.

## Запуск

1. Распакуйте весь архив в новую папку.
2. Windows: дважды нажмите **start-server.bat**. Linux/macOS: `sh start-server.sh`.
3. Нужен Python 3.8+; Node.js, npm и дополнительные Python-пакеты для игры не нужны.
4. Браузер откроется автоматически. Не закрывайте окно сервера во время игры. Если браузер не открылся, используйте напечатанный в окне адрес `http://127.0.0.1:…/index.html`.

**Не открывайте index.html напрямую с диска через file://.** Браузер блокирует модули Recast и module Worker. Это не ошибка WebGL и не причина отключать защиту браузера.
