# Движение NPC — версия 7

Полный проект поверх `AEGIS_ragdoll_stumbling_v6.zip`. Распакуйте в отдельную папку, запустите `start-server.bat` (Windows) или `start-server.sh` (Linux), откройте локальный адрес. Не запускайте игру через file://. Если используете прежнюю папку/сервер, обновите страницу без кэша.

## Что исправлено

- **Поза больше не замирает у видимых NPC.** Раньше после 22/45/90 условных метров скелет переходил на 30/15/10 Гц, хотя капсула продолжала двигаться каждый кадр. Теперь ноги, корпус, оружие и кисти видимого бойца обновляются вместе в каждом шаге симуляции. Скрытые бойцы остаются на редком обновлении; дистанционное отключение теней сохранено. Редкое обновление неподвижных видимых бойцов тоже убрано — дыхание и повороты не должны дёргаться.
- **Поворот с угловой инерцией.** NPC ограничивает скорость и ускорение разворота, использует короткую дугу через ±π. Обычный предел — 3 рад/с и 11 рад/с², в боевой реакции — 4,2 и 18. Интеграция подшагами до 1/120 с. Управление мышью игрока этим ограничением не затронуто.
- **Навигация не толкает бойца боком при повороте.** Желаемое направление переводится из старой локальной системы в новую с сохранением мирового вектора. Раньше ИИ вычислял направление до поворота, а мотор применял его уже после поворота.
- **Непрерывная фаза шага.** Микроостановки больше не перематывают цикл к .2/.7. Порог начала и окончания движения различается, чтобы столкновения и очень малая скорость не включали/выключали походку каждый кадр. Минимальная длина цикла согласована между контроллером и аниматором.
- **Корректный неполный шаг.** Место приземления использует действительно оставшуюся часть цикла, а не длительность полного замаха. Прерванный перенос стопы начинает движение из её текущей позиции. Корректирующий шаг не возобновляет обычный замах сразу с середины траектории.
- **Торможение и смена опоры.** При замедлении цель стопы допускает позднее уточнение, чтобы нога не приземлялась слишком далеко перед уже остановившимся телом. Корректирующий шаг начинается до чрезмерного вытягивания ноги.
- **Перенос веса без прежних повторяющихся глубоких приседаний.** Прогнозируется необходимая высота таза для предстоящей опоры; замах одной ноги сам по себе больше не опускает весь корпус. Настоящее ограничение досягаемости опорной ноги всё ещё имеет приоритет над косметическим сглаживанием.
- **Стопы не вращаются синхронно с капсулой.** В опоре сохраняется их направление; при переносе оно меняется плавно. На месте выполняются короткие последовательные шаги разворота.
- **Связность корпуса и рук.** Переход ходьба/бег и боковой наклон сглажены; взгляд немного опережает разворот тела. У безоружного NPC амплитуда и мах рук сглажены и привязаны к непрерывной фазе.
- **Снята лишняя работа ног.** Убраны восемь угловых моторов Rapier на персонажа, чей результат раньше немедленно перезаписывался вторым таким же IK-решением. Инерция центральных костей остаётся. Это не удаляет физические конечности рагдолла.

## Проверки

В `docs/NPC_MOTION_QA_V7.json` — результаты до/после и оговорки; в `tools/advanced-tests/npc-v7-before.json` и `npc-v7-after.json` — исходные измерения.

- 24 сценария прямого аниматора: ходьба, бег, разгон/торможение, поворот, боковое движение, малая переменная скорость; шаг времени 1/20, 1/30, 1/60 и 1/120 с.
- Реальный игровой цикл NPC: за 90 кадров видимая поза рассчитана 90 раз даже при принудительно заданном старом интервале 1/30, 1/15 или 0,1 с. Отдельно проверены видимые дистанции 30/60/100 м и редкое обновление скрытого бойца.
- 16 проверок поворота и 20 проверок сохранения мирового направления управления.
- 9 проверок IK и опорных контактов, 22 проверки рагдолла/stumbling; дополнительные результаты браузерной интеграции указаны в QA-отчёте.

На 60 Гц в контролируемом сценарии разворота максимальная измеренная скорость скачка стопы снизилась примерно с 36,16 до 8,12 м/с; при беге максимальная скорость вертикального изменения таза — с 4,17 до 0,76 м/с. Это пиковые разности соседних кадров в данном тесте, **не средняя скорость персонажа и не оценка FPS**. Полные метрики, включая не улучшившиеся показатели, сохранены в JSON.

## Границы результата

Это переработанная процедурная KCC/IK-анимация, не новый набор mocap-клипов и не полностью физический active-ragdoll для обычной ходьбы. Рагдолл, временные падения и stumbling из v6 сохранены; вставание остаётся анимационным смешиванием с проверкой опоры/просвета. Предельные повороты, сложный рельеф, разные размеры тела и произвольные сочетания боевых действий не проверены исчерпывающе.

Некоторые отдельные пиковые скорости колена и микродвижения таза в тестах не стали меньше — это не обещание нулевых рывков во всех ситуациях. Покадровые видимые позы увеличивают их CPU-бюджет; лишние вычисления ног удалены, но замера FPS на пользовательской видеокарте нет.

Общий `npm test` не полностью зелёный: остаётся прежний `runtime.cjs:167` — `occluded target position is not tracked`. Логика `combat.js` этим патчем не изменена; этот сбой ранее воспроизводился и на старой версии. Остальные отдельно перечисленные регрессии запускались отдельно, без изменения проверок ради зелёного результата.

## Повтор проверки

```sh
npm run build
npm run typecheck
npm run test:npc
npm run test:npc:browser
npm run test:locomotion
npm run test:ragdoll
npm run test:ragdoll:browser
```

Браузерным тестам нужны Playwright, Chromium и локальный сервер. Для NPC-тестов сервер по умолчанию `http://127.0.0.1:8774/`, адрес задаётся через `BASE_URL`, путь Chromium — `CHROMIUM_PATH`.
