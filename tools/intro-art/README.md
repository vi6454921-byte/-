# Иллюстрации оружия для экрана загрузки (v25)

Собственные векторные рисунки (вид справа, дуло вправо), детали — в миллиметрах по реальным габаритам.
Без чужих фотографий и текстур: всё рисуется кодом.

| Файл | Что внутри |
|---|---|
| `eng.py` | «движок» рисунка: детали-контуры, материалы (воронёная сталь, полимер, дерево, резина, стекло), блики, фаски, износ, шум, древесные волокна → SVG |
| `guns.py` | АКМ, АК-74М; `build(id)` и запуск из командной строки |
| `guns2.py` | HK416 A5, SCAR-H, MP5A3, Remington 870, СВД с ПСО-1 |
| `render.cjs` | растеризация SVG в Chromium (playwright) с прозрачным фоном |
| `build.sh` | SVG → PNG → WebP (качество 85) в `assets/intro/` |
| `manifest.jsonl` | габариты картинок (`w`, `h`, `x0`, `x1` — где затыльник и дуло в долях ширины) для размерной линии в `js/app/intro.js` |

Пересобрать: `bash tools/intro-art/build.sh` (нужны python3, node + playwright, ImageMagick 7; путь к Chromium — `CHROMIUM_PATH`).
Один рисунок: `bash tools/intro-art/build.sh svd`. Готовые WebP весят 30–57 КБ.
