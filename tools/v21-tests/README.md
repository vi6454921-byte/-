# Стенды v21 (Playwright + Chromium)

Каждый стенд открывает игру в безголовом Chromium, ставит одну изолированную ситуацию и пишет JSON/PNG в
`tools/v21-tests/out/` (или в `OUT_DIR`). Запуск:

```
python3 tools/serve.py --no-browser --port 8000        # в корне игры, отдельный терминал
npm i playwright                                       # один раз (или CHROMIUM_PATH=путь к Chrome)
BASE=http://127.0.0.1:8000/ MAP=forest_map_camp SEC=1 node tools/v21-tests/render_prof.cjs
```

«Слабый ПК»: без видеокарты Chromium рисует программно (SwiftShader), это и есть самый тяжёлый случай.
Для дополнительного замедления процессора — `THROTTLE=4` у `intro_probe.cjs`.

| Стенд | Пункт | Что проверяет |
|---|---|---|
| `trace_check.cjs` | 1 | 300 случайных лучей: новый трассировщик против старого (`mode='legacy'`) на одной сцене — совпадение попаданий и время |
| `trace_bench.cjs` | 1 | время выстрела в небо / горизонтально / в землю (медиана, p90) |
| `opt_check.cjs` | 1 | один кадр в 4 стороны с отсечением и без (переключатели `cull.on` и `AEGIS_TINY.on` на том же кадре): попиксельное сравнение, бойцы в кадре не скрыты, пули попадают в то же дерево |
| `render_prof.cjs` | 1 | кадр на респауне: время симуляции и рендера, вызовы отрисовки и треугольники по категориям, GPerf |
| `load_cmp.cjs` | 1, 4 | время загрузки до боя (`NO3D=1` — без 3D-заставки) |
| `intro_probe.cjs` | 4 | заставка: первый кадр, кадры/с, вызовы отрисовки, снимки слайдов (`THROTTLE=4` — CPU ×4 медленнее) |
| `sector_probe.cjs` | 2 | сектора: границы, базы, флаги, респауны, боты не выходят за линию |
| `gait2.cjs` | 5 | бег/ходьба бота: доля опоры, фаза полёта, частота и асимметрия шагов, колебание и ускорение таза, рывки коленей на дальних LOD |
| `laser_dot.cjs` | 6 | яркость пятна и луча лазера на бойце и на земле на разных дистанциях |
| `mg_probe.cjs` | 7 | M2HB: посадка (F), обзор мышью, стрельба, патроны, углы, камера наводчика |
| `ladder_all.cjs` | 8 | все лестницы карты: подъём, спуск сверху, сход внизу |

Чистые тесты без браузера: `node tools/ai-tests/sectors.cjs`, `teams.cjs`, `orders-sim.cjs`,
`node tools/trace_regression.js`.
