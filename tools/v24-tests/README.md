# Стенды v24: вызовы отрисовки, дальние цели, снимки

Запуск — в корне игры, сервер поднят (`python3 tools/serve.py --no-browser --port 8000`). Браузер — Chromium из
Playwright или свой (`CHROMIUM_PATH`), рендер — SwiftShader («слабый ПК без видеокарты»).

```
node tools/v24-tests/abprof.cjs > out/abprof_forest.json   # ОДИН И ТОТ ЖЕ кадр трижды: v24 / без заменителей / без заменителей и склейки (= как v23)
BASE=http://127.0.0.1:8100/ node tools/v24-tests/abprof.cjs     # тот же кадр (то же зерно) в другой сборке, например v23
node tools/v24-tests/drawprof.cjs                          # один кадр: вызовы и треугольники по группам сцены, основной проход и тени
QS='&proxy=0' node tools/v24-tests/drawprof.cjs            # то же без дальних заменителей
QS='&batch=0&proxy=0' node tools/v24-tests/drawprof.cjs    # без батчинга и заменителей
BASE=http://127.0.0.1:8100/ node tools/v24-tests/drawprof.cjs   # другая сборка (например, v23) на своём порту

MAP=stroyka_zarechye_v2 node tools/v24-tests/v24check.cjs  # снимки: от первого лица, небо, цель на 20–160 м, укрытия
MAP=polygon PARTS=dist DIST=20,35,60,100,135 W=1280 H=720 node tools/v24-tests/v24check.cjs
MAP=stroyka_zarechye_v2 WEATHER=morning PARTS=signs node tools/v24-tests/v24check.cjs   # вывески спереди и сзади

MAP=polygon node tools/v24-tests/proxy_ab.cjs              # заменитель против полной модели: тот же кадр, та же поза
```

| Скрипт | Что делает |
|---|---|
| `abprof.cjs` | честное A/B: кадр после 2 с боя (зерно `Math.random` — `SEED`, по умолчанию 1) рисуется трижды без шага симуляции — как в v24; с `GLod.setProxy(false)`; затем ещё и с разобранной склейкой (`dispose`, отсечение мелочи пересобирается) — то есть как рисовал v23. Вызовы и треугольники по группам (`env`, `soldier`, `proxy`, `weaponMount`, прочее), основной проход и тени, дистанции видимых бойцов. Между запусками положение ботов разное, поэтому сравнивать по отдельным запускам `drawprof` нельзя — только так |
| `drawprof.cjs` | 2 с боя, затем один кадр с перехватом `renderBufferDirect`: число вызовов и треугольников по корневым группам сцены (`soldier`, `weaponMount`, `env/…`, `level_batches`), отдельно основной проход и карта теней; статистика батчинга (`G.batch()`) и заменителей (`GLod.stats().proxy`) |
| `v24check.cjs` | `fp` — кадр от первого лица (канва + снимок с интерфейсом, положение счёта и полосы команд); `sky` — небо вверх и назад; `dist` — противник на заданных дистанциях по самому длинному чистому лучу: вызовы и треугольники именно этого бойца, включён ли заменитель, контраст цели (сколько пикселей отличаются от кадра без цели больше чем на 18 по яркости и средний перепад) — заменитель вкл/выкл; `cover` — укрытие у точки возрождения; `signs` (только по запросу) — отдельно стоящие вывески и дорожные знаки спереди и сзади (центр кадра 1:1, лист `out/<…>_signs.png`): с оборота надпись должна читаться, а не зеркалиться |
| `proxy_ab.cjs` | дальний заменитель против полной модели в одном и том же кадре (камера и поза заморожены, кадр рисуется `renderer.render` без эффектов бодикама): для каждой дистанции `D1080` (размер цели на экране — как при 1920×1080 на этой дистанции) — снимок с полной моделью, с заменителем и без цели; маска цели (яркость отличается от кадра без цели больше чем на 10), совпадение масок (IoU), средний контраст цели к фону, средняя разница цвета заменителя и оригинала; лист снимков `out/proxy_ab_<карта>.png` и `out/proxy_ab_<карта>.json` |
| `lib.cjs` | общая обвязка: запуск браузера, загрузка карты, шаги симуляции и кадры без цикла игры |

env: `BASE`, `CHROMIUM_PATH`, `MAP` (`polygon` — полигон), `Q` (качество, `low`), `QS` (доп. параметры адреса),
`WEATHER` (`day` / `morning`), `PARTS`, `DIST`, `W` / `H` (размер окна `v24check`, по умолчанию 640×360), `TAG`,
`OUT_DIR` (по умолчанию `tools/v24-tests/out/`), `FRAMES` (кадров перед замером в `drawprof` / `abprof`, 4), `SEED` (`abprof`).

Результаты v24 — в `out/` (`abprof_*.json`, `drawprof_*.json`, `proxy_ab_*.json`, снимки `*.png`); `abprof_forest_v23.json` —
v23 в отдельном запуске (для справки: бойцы в кадре другие, с v24 напрямую не сравнивается).
