# Стенды v22 (Playwright + Chromium)

Один запуск `run.cjs` = одна загрузка карты + один или несколько сценариев. Сценарий — файл `*.js` рядом:
тело async-функции, которое выполняется в странице игры (`__GAME`, `THREE`, `GPhysics`, …) и возвращает
JSON. Результат пишется в `tools/v22-tests/out/<сценарий>.json` (или в `OUT_DIR`) и коротко печатается.
Рендер на время стендов выключен (как в стендах v21) — считается только симуляция.

```
python3 tools/serve.py --no-browser --port 8000        # в корне игры, отдельный терминал
npm i playwright                                       # один раз (или CHROMIUM_PATH=путь к Chrome)
MAP=angar_map SEC=1 node tools/v22-tests/run.cjs angar_orders.js angar_doors.js
MAP=forest_map_camp SEC=1 node tools/v22-tests/run.cjs turn_clips.js flank.js smoke_los.js fall.js loot.js voice.js voice_pack.js
MAP=stroyka_zarechye_v2 SEC=1 node tools/v22-tests/run.cjs zarechye_battle.js fence_vault.js
MAP= node tools/v22-tests/run.cjs gait_ab.js gait_trace.js       # пустой MAP — полигон (ровное место)
```

Порядок важен: сценарии идут в одной странице друг за другом, бой продолжается. `fence_vault.js` на время
работы выключает мышление и огонь ботов (иначе бойца убивают посреди попытки) и потом включает обратно,
но телепортирует бойца — поэтому его лучше ставить последним.
