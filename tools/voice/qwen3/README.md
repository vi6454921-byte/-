# Голоса бойцов v24–v26: Qwen3-TTS (VoiceDesign → клонирование → отбор → пакет)

Четыре голоса отряда сделаны **с нуля** нейросетевым синтезом, без записей реальных людей:

| ключ | позывной | характер | референс |
|---|---|---|---|
| `grom` | Гром | глубокий бас, ветеран-командир, спокойно и жёстко | `design/grom_13` |
| `hrip` | Хрип | сиплый низкий баритон, усталый сержант | `design/hrip_7` |
| `sokol` | Сокол | молодой тенор, быстро, на адреналине | `design/sokol_5` |
| `tihiy` | Тихий | ровный баритон, связист, чётко | `design/tihiy_5` |

Модели: **Qwen3-TTS** (Alibaba Qwen, Apache-2.0) — `Qwen3-TTS-12Hz-1.7B-VoiceDesign` (голос по текстовому описанию) и
`Qwen3-TTS-12Hz-0.6B-Base` (клонирование по 7-секундному референсу). Движок — **qwen3-tts** на чистом C
(github.com/gabriele-mastrapasqua/qwen3-tts, MIT), int8, работает на CPU без Python/PyTorch.
Сгенерированный звук — собственность проекта, ограничений «только некоммерческое» нет (в отличие от прежнего
голоса Piper `ruslan`, CC BY-NC-SA, — он из пакета удалён).

## Конвейер

```
# 0. движок и модели (≈6 ГБ на диске, сборка 2–3 мин)
git clone https://github.com/gabriele-mastrapasqua/qwen3-tts $TTS/qwen3-tts && cd $TTS/qwen3-tts && make
./download_model.sh   # нужны 1.7B-VoiceDesign и 0.6B-Base (каталоги qwen3-tts-voice-design, qwen3-tts-0.6b-base)
pip install vosk soundfile numpy; # + vosk-model-small-ru-0.22 в $TTS
export TTS=/путь/к/каталогу
./design.sh                 # 1–2: голоса по описаниям voices.txt → design/*.wav, refs/*.wav (обрезка тишины)
./clone_all.sh 1            # 3: все фразы phr.py каждым голосом, сид 1 (≈8 с на фразу, ≈13 мин на голос на 2 ядрах)
python3 check_clones.py grom,hrip,sokol,tihiy 1   # 4: Vosk-распознавание + темп речи → BAD-список
./run_clone.sh hrip 8091 2 close4,kill3           # 5: переозвучить плохие фразы другим сидом (2, 3…)
python3 check_clones.py hrip 2 close4,kill3
python3 build_pack.py       # 6: лучший дубль каждой фразы → обработка → ../../../assets/snd/voice_pack.js
```

* `voices.txt` — описания голосов (английский: так модель понимает лучше) и сиды отобранных дублей.
  Новый голос: добавить строку, прогнать `design.sh`, послушать `design/*.wav`, перенести лучший в `refs/`.
* `phr.py` — словарь фраз (`PHR`). Тексты дублируются в `js/polygon/31c_voice.js` (субтитры, запасной Web Speech).
* `build_pack.py` — выбирает дубль с максимальным совпадением распознанного текста (дубли с неестественным темпом —
  вне 7–22 симв./с — штрафуются; при равенстве берётся меньший сид), обрезает тишину, срез 85 Гц, −1,5 дБ@200 Гц, +2,5 дБ@3 кГц (разборчивость в рации),
  −1,5 дБ@7,5 кГц, компрессор 3:1, громкость речи −17 дБFS, мягкий лимит, MP3 24 кГц 40 кбит/с моно.
  Высоту и темп не трогаем — тембр остаётся живым. Игра сама добавляет «рацию» и разброс ±4 % (`RATES`).
* Проверка в игре: `cd tools/v22-tests && node run.cjs voice_pack.js` (все ключи пакета играют, субтитры совпадают).

Память: сервер 0.6B ≈ 1,9 ГБ, VoiceDesign 1.7B ≈ 3,7 ГБ. Не запускать одновременно с браузерными тестами на машине с 4 ГБ.

## v25: живые переговоры (phr25.py → 588 клипов, по 147 на голос)

Те же четыре голоса и референсы, новый набор фраз — как говорят люди, а не как пишет устав:

* доклад о контакте — направление **относительно говорящего** («впереди справа», «сзади», «слева») и дистанция
  словами («рядом», «метров тридцать / пятьдесят / сто / двести»); без азимутов, «двухсотых» и «трёхсотых».
  8 направлений × 5 дистанций, у каждого голоса свой порядок трёх шаблонов («Контакт! …», «Противник …», «Вижу противника! …»);
* короткие реплики боя (`FIX`): «Готов», «Минус один», «Меня зацепило!», «Есть раненый!», «Граната пошла!», «Магазин!»…;
* переговоры по рации в затишье (`RADIO`, роли a/b разными голосами) и разговоры вживую рядом (`DIALOG`);
  часть разговоров и короткие команды (`WHISPER`) — **шёпотом**.

Шёпот делается без нейросети (`whisper.py`): огибающая спектра обычной речи (кепстральное сглаживание убирает
основной тон, остаются форманты) возбуждается шумом со случайной фазой, низ < 300 Гц убран, 2–5 кГц чуть
подняты, форманты +3–5 %. Затем тот же EQ без компрессии, громкость −21 дБFS (обычная речь — −17 дБFS).

```
export TTS=/путь/к/каталогу V25=$TTS/v25 && mkdir -p $V25
python3 phr25.py $V25/phr25.json          # словарь фраз → JSON (печатает число клипов)
./run25.sh grom 8091 1                     # озвучить все фразы голосом (сервер 0.6B-Base + clone25.py) → $V25/clone/
python3 check25.py grom,hrip,sokol,tihiy 1 # Vosk + темп → $V25/check/asr25_s1_*.json и BAD-список
./run25.sh hrip 8091 2 kill1,ct3_2         # переозвучить плохие другим сидом, снова check25.py
python3 build_pack25.py                    # лучший дубль → обработка (шёпот — whisper.py) → assets/snd/voice_pack.js
```

Тексты фраз дублируются в `js/polygon/31c_voice.js` (субтитры, запасной Web Speech): при правке `phr25.py`
обновить и его. Проверка в игре — как в v24 (`tools/v22-tests/voice_pack.js`).

## v26: армейский радиообмен, напряжённые реплики, проверка ударений, Opus (phr26 → gen26 → check26 → build_pack26)

Новый полный пакет (206 фраз × 4 голоса = 824 клипа): «двухсотый/трёхсотый», «минус», «работаю», «прилёт»,
радиообмен по правилам («Второй, я Первый. Приём.» — «Второй на приёме.» — … — «Принял. Конец связи.»),
доклады о потерях на все случаи (0 / 1–2 «трёхсотых», тяжёлый, 1–2 «двухсотых», смешанные), штурм помещения,
БК. Тексты — `phr26.py` (с «+» перед ударной гласной для проверки ударений; в синтез идут без «+»), дублируются в
`js/polygon/31c_voice.js` (субтитры, запасной Web Speech).

* **Тембр** — только x-vector диктора (`--xvector-only`, без ICL-текста референса): голос не «заимствует»
  интонации и шумы референса. x-vector'ы — `refs26/<голос>.bin` (из ~30 с клипов v25: `extract_v25.py` →
  `mkref26.py` → `xvec26.sh`).
* **Напряжённые реплики** (граната, прилёт, ранение, «двухсотый», «прижали», контакт вплотную — 34 на голос,
  `meta.urgent`) — x-vector, сдвинутый к вектору «злости» из пресетов qwen3-tts на 12 % нормы
  (`refs26/<голос>_ang12.bin`): F0 +4–5 полутонов (Гром 186 → 250 Гц, Сокол 246 → 307 Гц), спектр ярче,
  распознавание не хуже. 18 % и больше — уже другой человек, поэтому 12 %.
* **Ударения.** Знак ударения U+0301 модель читает как лишний звук («ю/й») — не используется. Вместо этого каждый
  дубль проверяет `check26.py`: (1) Vosk — совпадение текста и темп 6–22 симв./с; (2) фонемы — wav2vec2
  XLSR-53 eSpeak (IPA) против ожидания из текста с «+» (выравнивание DP): в русском безударные «о/а»
  редуцируются ([ɐ]/[ə]), ударная «о» полная ([o]), «е» — [e] / [ɪ]. `serr` — взвешенное число ударений «не туда».
  Плохой дубль (`r < 0,75`, `serr ≥ 0,9` или темп вне 6–22) переозвучивается следующим сидом (до 4).
  Проверено на контрольном наборе: дубли с правильным ударением — `serr 0`, с ударением-диакритикой — пойманы.
* **Пакет** — `build_pack26.py`: лучший дубль по оценке (текст, ударения, темп), обрезка тишины, срез 80 Гц,
  −1 дБ@250 Гц, +1,5 дБ@3 кГц, −1,5 дБ@7,5 кГц, компрессор 2:1 (в v25 3:1 и +2,5 дБ — голос был плоским,
  «цифровым»), речь −17 дБFS, напряжённые −15,5, шёпот −21 (`whisper.py`), **Ogg Opus 32 кбит/с VBR** (MP3 на
  24 кГц давал «звон» на шипящих). В пакете `V.ver = 26`, `V.fmt = 'opus'`, тексты `V.tv`, длительности `V.u`.
  Отчёт по каждому клипу — `pack_out/report.tsv`.

```
export TTS=/путь/к/каталогу V26=$TTS/v26 && mkdir -p $V26 $TTS/refs && cp refs26/*.bin $TTS/refs/
python3 phr26.py $V26/phr26.json          # словарь → JSON (печатает число клипов)
./gen26.sh 1 4                            # проход 1 (сид 1) → check26 → проходы 2–4 только для плохих дублей
                                          # (serve26.sh + client26.py; ≈7 с на фразу на 2 ядрах, ≈2,5 ч всего)
cd $V26 && python3 /путь/tools/voice/qwen3/build_pack26.py   # → assets/snd/voice_pack.js
```

Память: сервер 0.6B ≈ 3,3 ГБ (int8, -j 2), wav2vec2 ≈ 1,3 ГБ — `gen26.sh` запускает их по очереди. Проверка
в игре: `node tools/v22-tests/run.cjs ../v26-tests/voice26.js` (пакет v26/Opus, декодирование, сцены радиообмена,
доклады о потерях, штурм) и `../v22-tests/voice_pack.js`.
